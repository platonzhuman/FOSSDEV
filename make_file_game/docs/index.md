# ПОДРОБНАЯ ДОКУМЕНТАЦИЯ НА ВСЕ СЛУЧАИ ЖИЗНИ КАК ГОВОРИТЬСЯ ^_^


## Что нужно знать заранее

Игра эта работает прямо в терминале и в ней нету никакого интерфейса — только поле, координаты и твой ввод ^_^

## Установка с нуля (даже если ты впервые видишь терминал)

1. Открой терминал (консоль, PowerShell, cmd . . . )
2. Склонируй репозиторий к себе:
   ```bash
   git clone https://github.com/platonzhuman/FOSSDEV
   ```
3. Зайди в папку с игрой:
   ```bash
   cd FOSSDEV/make_file_game
   ```
   (если ты уже внутри репозитория, просто `cd make_file_game`)
4. Создай виртуальное окружение и установи зависимости:
   ```bash
   make venv
   make install
   ```
   После этого в папке появится `.venv`, а внутри него — все нужные инструменты.
5. Запускай:
   ```bash
   make run
   ```
   Вроде должно бытьту тебя все норм ^_^


## Как играть

Поле 3×3. Координаты клеток — это **строка и столбец**, оба от 0 до 2.  
Пример: `0 0` — левый верхний угол, `2 1` — третья строка, второй столбец.

- Игрок 1 ставит **X** (крестики).
- Игрок 2 ставит **O** (нолики).
- Ходите по очереди. Программа сама подскажет, чей сейчас ход.
- Побеждает тот, кто соберёт три своих знака в ряд, столбец или диагональ.
- Если заполнили всё поле, а победителя нет — ничья.

## Если что-то пошло не так

**Проблема:** `make: command not found`  
→ У тебя не установлен `make`. Поставь его:  
  - Ubuntu/Debian: `sudo apt install make`  
  - macOS: `xcode-select --install`  
  - Windows: используй WSL или установи [GnuWin32](http://gnuwin32.sourceforge.net/packages/make.htm)

**Проблема:** `python3: command not found`  
→ Нужен Python 3.10 или новее. Скачай с [python.org](https://python.org), при установке не забудь галочку «Add Python to PATH».

**Проблема:** `No module named pytest` (после `make test`)  
→ Забыл выполнить `make install`. Сделай это, все зависимости подтянутся.

**Проблема:** `ModuleNotFoundError: No module named 'krest_nole'`  
→ Ты пытаешься запустить игру не через `make run`. Если запускал вручную, используй `.venv/bin/python src/krest_nole.py`. Но проще всегда делать `make run`.

**Проблема:** Ничья, а программа не завершилась  
→ Такого быть не должно, но если вдруг — нажми `Ctrl+C`, чтобы выйти.
