# Крестики-нолики

Игра на двоих прямо в терминале, скорее больше для тех людей, которые понимают за индексы, но это пока ^_^
Максимально проста и быстрая в тоже время, чисто для тех моментов, когда вам с друзьями нечего делать 

## Установка и запуск

```bash
git clone https://github.com/platonzhuman/FOSSDEV
cd make_file_game
make venv
make install
make run
```

## Make-команды

| команда | что делает |
|---------|-------------|
| `make venv` | создает виртуальное окружение `.venv` |
| `make install` | устанавливает зависимости |
| `make run` | запускает игру |
| `make test` | прогоняет тесты |
| `make typecheck` | проверяет типы |
| `make lint` | проверяет стиль кода |
| `make format` | автоформатирует код |
| `make check-requirements` | сравнивает импорты с `requirements.txt` |
| `make check` | запускает `typecheck`, `lint`, `check-requirements` вместе |
| `make clean` | удаляет временные файлы |

## Правила игры

У вас есть игровое поле 3×3, где игроки по очереди вводят координаты клетки в формате `x y` (строка и столбец, от 0 до 2) ^_^  
Первый игрок играет крестиками (`X`), второй -> ноликами (`O`).  
Побеждает тот, кто первым выстроит три своих знака в ряд, столбец или диагональ.  
Если все клетки заполнены, а победителя нет -> ничья.
