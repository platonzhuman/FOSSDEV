## Установка

```bash
pip install --index-url https://test.pypi.org/simple/ terminal-color-tool
```

После установки становится доступна команда `terminal-color`.

## Использование

### Изменение цвета вводимых команд и фона

Чтобы изменить цвет текста, который вы набираете в терминале, или цвет фона, используется `eval` и `export PS1`.  
Этот метод работает в `zsh`, `bash` и других оболочках.

**Цвет текста (красный):**
```bash
eval "$(terminal-color red)"
```
После выполнения приглашение и вводимые символы станут красными.

**Цвет фона (зелёный):**
```bash
eval "$(terminal-color bg_green)"
```
Фон приглашения и всего последующего ввода становится зелёным.

**Сброс к стандартным настройкам:**
```bash
eval "$(terminal-color --reset)"
```

### Быстрый вывод цветного текста

Если не использовать `eval`, команда просто выводит ANSI-код, который действует на всё, что будет напечатано дальше, пока не выполнен сброс.

```bash
terminal-color red
echo "Этот текст будет красным"
terminal-color --reset
```

### Стили текста

Жирный и подчёркнутый шрифт применяются без `eval`:

```bash
terminal-color bold       # жирный
terminal-color underline  # подчёркнутый
```

Сброс стилей:
```bash
terminal-color --reset
```

## Доступные цвета и стили

### Цвета текста
`red`, `green`, `blue`, `yellow`, `cyan`, `magenta`, `white`, `black`

### Цвета фона
`bg_red`, `bg_green`, `bg_blue`, `bg_yellow`, `bg_cyan`, `bg_magenta`, `bg_white`, `bg_black`

### Стили
`bold`, `underline`

## Специальные команды

- `terminal-color --list` – показать все доступные цвета с примерами.
- `terminal-color --reset` – сбросить цвет и стили (без `eval` сбрасывает только активный ANSI-код; с `eval` также восстанавливает PS1).

## Как это работает

Программа использует стандартные **ANSI escape-последовательности**, которые понимают большинство современных терминалов.  
Для смены цвета вводимого текста и фона используется механизм `PS1` – переменной оболочки, задающей вид приглашения. Команда `terminal-color red` выводит строку вида `export PS1='...'`, а `eval` применяет её к текущей сессии.  
Без `eval` можно просто вывести код цвета, и он будет действовать на весь последующий вывод (но не на уже введённые символы), пока не будет сброшен.
